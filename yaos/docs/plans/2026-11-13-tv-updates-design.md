# Обновления FreeCast TV по сети

## Цель

Устанавливать новые версии на телевизоре без флешки и аккаунта GitHub. В приложении видна новая версия; пользователь скачивает APK и подтверждает установку штатным экраном Android.

## Публикация

GitHub Actions собирает release APK по тегу `vX.Y.Z`, запускает тесты и публикует APK как asset GitHub Release. `versionName` берётся из тега, а `versionCode` монотонно растёт. Один постоянный keystore хранится вне Git; Actions получает его и пароли через GitHub Secrets. Публикация не выполняется без настроенного ключа. Debug-артефакты остаются для разработки, но не предлагаются для OTA.

## Приложение

На главном экране появляется кнопка «Обновление». При запуске приложение проверяет `releases/latest` публичного репозитория и сравнивает версии. По нажатию оно скачивает единственный asset `FreeCast-TV-X.Y.Z.apk` в приватный cache, проверяет размер и SHA-256 из GitHub API, сверяет package ID и более высокий `versionCode`, затем передаёт content URI штатному установщику через FileProvider. На Android 8+ при необходимости открывается настройка «Установка неизвестных приложений» для FreeCast TV. Установка всегда требует подтверждения пультом. Ошибки сети, отсутствующий релиз и отклонённая установка показываются в интерфейсе; при отмене старая версия продолжает работать.

## Миграция и проверка

Текущие APK из Actions подписаны временными debug-ключами. Переход на постоянный release-ключ потребует разовой переустановки; APK первого релиза можно скачать на самом ТВ через браузер, без флешки. После этого обновления устанавливаются поверх приложения с сохранением данных. Проверка: Gradle-тесты и release-сборка в Actions, соответствие имени/версии APK и asset, ручная проверка установки на YaOS. Без физического ТВ автоматическая проверка последнего шага невозможна.
